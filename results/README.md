# Results

The logs behind the figures and tables of the main README. Nothing here needs an API key to read.

- **`ga_runs/<model>/run_0{1,2,3}.jsonl`** - GA logs: 7 models x 3 independent runs. One JSON object per
  generation, as written by [`logging_utils.py`](../src/llm_abm_ga/logging_utils.py): `generation`,
  `population` (50 individuals, each `[system_bits, user_bits]`), `fitness_scores`, `mean_fitness`,
  `best_fitness` and `best_individual`. Settings: 8 prompt components, 15 generations, 50 prompts per
  generation, 80,000 buyers, 10 periods, tournament size 6, 5 elites, mutation rate 0.1 (the defaults of
  [`scripts/run_ga.py`](../scripts/run_ga.py)). The client in this repository runs the LLM at
  temperature 0 where the API accepts it (the `gpt-5-*` models take no temperature and run with
  `reasoning_effort="low"`), caps answers at 30 tokens and sets the Gemini thinking budget to 0. The
  single user bit maps to a blank phrase, so mutation can flip it without changing the prompt.
- **`optimized_vs_baseline/`** - 20 independent markets with 1 GA-optimized firm (genome `11100110`)
  and 9 random-prompt firms, played by `gpt-3.5-turbo` at temperature 0 (100,000 buyers, 10 periods).
  `log_fig_8.json` has the per-market profits, `optimized_vs_baseline_results.csv` the same in a table.
- **`summary.md`, `summary.json`** - every number quoted in the README, generated by
  [`analysis/make_figures.py`](../analysis/make_figures.py) (a test checks that they are up to date).

Output of your own runs goes to `results/logs/` (git-ignored).
